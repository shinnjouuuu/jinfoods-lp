# map-src — 受託エリアの概略図の元データ

会社概要ページ（about.html `#area`）とトップの受託施設一覧（index.html `#facility`）で使っている
概略図（`p-area-map`）の、下地（大分の市町村境界）を作る材料。**本番には出さない**（`.vercelignore` で除外）。

2026-09-30 に、FV を作った会話の一時フォルダから移した（一時フォルダは会話が終わると消えるため）。

## 入っているもの

| ファイル | 中身 |
|---|---|
| `make-land.py` | 市町村境界を、図と同じ原点・縮尺の SVG `<g class="p-area-map__land">` に書き出す |
| `N03-21_44_210101.json` | 元データ。大分県の市町村境界（2021年1月1日時点） |
| `area-map-land.svg.html` | `make-land.py` の出力。いまサイトに入っている下地と同じもの |

## 図の決まり（変えると下地と点がずれる）

- 原点＝本社：**北緯 33.22699・東経 131.59702**（OpenStreetMap の「大分市大道町五丁目」）
- 縮尺：1km = 11（SVG の単位）、北が上。viewBox は `-235 -125 470 345`
- 横は緯度の cos で縮める近似（20km 四方なら誤差は無視できる）
  - x = (経度 − 131.59702) × 111.32 × cos(33.22699°) × 11
  - y = −(緯度 − 33.22699) × 110.57 × 11
  - 下の表の地区の点は、南北の係数に 110.95 を使って出していた（make-land.py は 110.57）。
    差はいちばん遠い犬飼でも 0.6（約50m）で、見た目は変わらない。新しく足す点は上の式でよい
- 受託先のある3市（大分市・別府市・豊後大野市）は `p-area-map__city--served`（ごく薄い朱）
- 図の注記に出典を必ず入れる：「地図：国土数値情報（行政区域データ）（国土交通省）を加工して作成」

## 作り直す

```bash
cd ~/projects/lp/jinfoods-lp && python3 map-src/make-land.py
```

出力（`map-src/area-map-land.svg.html`）の `<g>…</g>` を、次の3か所に貼り直す。

1. `about.html` の `.p-area-map__svg` の中、`<title>` の直後
2. `index.html` の `#facility` の `.p-area-map__svg` の中、`<title>` の直後
3. `wp-theme/jinfoods/template-parts/area-map-land.php`（PHP のヘッダーコメントの下）

WordPress の会社概要ページは、LP の about.html から `wp-theme/export-content.py` で書き出して流し込む。
